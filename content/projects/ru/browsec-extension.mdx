## Контекст

Browsec — коммерческий VPN, основной продукт которого — браузерное расширение.
Я работал над расширением в сборках для Chrome, Firefox и Opera.

## Что интересного

- **Одна кодовая база, три браузера.** Различия манифестов и API (MV2/MV3,
  proxy API, особенности storage) изолированы за небольшим платформенным
  слоем; продуктовый код остаётся браузер-агностичным.
- **Релизная дисциплина.** Мультибраузерный пайплайн сборки со smoke-тестами
  на Selenium гейтит каждый релиз — когда пользователей миллионы, сломанный
  конфиг прокси — это инцидент, а не баг-репорт.

## Результат

Выпущено несколько продакшен-релизов (линейка v3.9x). Коммерческий
production-опыт с платформой WebExtensions на большом масштабе пользователей.
