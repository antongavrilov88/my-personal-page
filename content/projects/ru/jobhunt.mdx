## Задача

Серьёзный поиск работы — это конвейер: десятки вакансий, и каждой нужны
адаптированное резюме, сопроводительное письмо и исследование компании.
Таблицы не масштабируются, а типовые трекеры не делают работу за вас.

## Что я сделал

Доска в стиле Trello, где каждая карточка — отклик. При открытии карточки
появляется боковая панель: описание вакансии, адаптированное резюме,
сгенерированное сопроводительное письмо и чат с AI-агентом, у которого есть
полный контекст отклика.

```text
React + TS (Kanban UI)
   │  REST + SSE-стриминг
FastAPI (async) ── Claude-агенты ── адаптация CV / письма / рисёрч компаний
   │
PostgreSQL + миграции Alembic · Docker Compose
```

Ключевые решения:

- **SSE вместо WebSockets** для стриминга агентов — однонаправленному потоку
  токенов не нужен дуплексный канал, а SSE бесплатно переживает прокси и
  переподключения.
- **Инструменты агента, а не «суп из промптов».** Каждая способность агента
  (прочитать CV, получить вакансию, изучить компанию) — типизированный
  инструмент; модель сама их комбинирует.
- **Асинхронный SQLAlchemy 2.0** на всём пути — вызовы агентов долгие, а API
  остаётся отзывчивым.

## Результат

Production-ready, пользуюсь ежедневно в собственном поиске. Репозиторий
демонстрирует full-stack ownership: типизированный API-клиент, миграции,
деплой в Docker, CI.
