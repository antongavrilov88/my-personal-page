## Задача

Коммерческие VPN — чёрный ящик; собственный VPN для семьи на нескольких
устройствах требует провижининга, жизненного цикла ключей и наблюдаемости —
настоящая системная задача, достаточно компактная, чтобы владеть ею целиком.

## Что я сделал

```text
Telegram-бот (UX для пользователей)
   │
Go-сервис (chi) ── провижининг устройств · жизненный цикл ключей · health-чеки
   │
PostgreSQL (миграции Goose)          WireGuard-пиры (облачные VM)
   │                                     ▲
GitHub Actions ── деплой ── Terraform ───┘  (инфраструктура как код)
```

- **Go-сервис** владеет записями устройств, генерацией конфигов WireGuard-пиров
  и их жизненным циклом (создание / заморозка / отзыв); пользователи работают
  через Telegram-бота — без кастомных клиентских приложений.
- **Terraform** поднимает облачные VM; тот же код пересобирает весь стек с
  нуля — это одновременно и план аварийного восстановления.
- **Операции как артефакты:** runbooks, скрипты заморозки, задания на бэкап и
  его проверку — скучные детали, которые делают сервис продакшеном, а не
  игрушкой.

## Результат

Работает в продакшене для устройств семьи. Проект — мой системный противовес
фронтенду: сети, IaC, миграции и операционная дисциплина.
